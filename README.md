## Objective
To identify standard network hardware components (such as Network Interface Cards, switches, routers, and network cables), understand their functions and connections, inspect/configure basic network settings, and use diagnostic commands to identify and troubleshoot connectivity issues in a small office network.

## Topics Covered
- **Network Hardware & Media:** Network Interface Cards (NICs), Ethernet switches vs. hubs, routers, RJ-45 connectors, and twisted-pair (Cat5e, Cat6, Cat6a), fiber-optic, and coaxial cables.
- **Core Networking Concepts:** LAN vs. WAN, packets vs. frames, IPv4 addresses and private address ranges (RFC 1918), subnet masks, default gateways, DNS, DHCP, and MAC addresses.
- **Configuration & Diagnostic Commands:** `ipconfig` (`/all`, `/release`, `/renew`, `/flushdns`), `ping`, `tracert` / `traceroute`, `nslookup`, `arp -a`, `getmac`, `netstat`, `route print` / `ip route`, and `hostname`.
- **Troubleshooting Workflow:** A 9-step logical troubleshooting sequence starting from physical checks up to routing and DNS verification, plus common symptom-to-solution guides.
- **Viva-Voce & Reference:** 25 common viva questions with answers, a quick Windows/Linux/macOS command reference, and a pre-submission self-check.
